Programa de Orientação Acadêmica — Versão 3.0

Publique os quatro arquivos index.html, styles.css, app.js e dados.json na RAIZ do repositório GitHub Pages, substituindo as versões anteriores. Preserve os nomes e as letras minúsculas.

O regulamento é acessível mesmo se dados.json não carregar, porque o link está no HTML e também fixado em app.js.

Teste após publicar:
1. Abra a página em aba anônima ou com Ctrl+F5.
2. Clique em "Consultar o regulamento" no topo.
3. Clique em "Acessar regulamento completo (PDF)".
4. Confira se as seções e dúvidas frequentes aparecem.
5. Se necessário, confira F12 > Console e Network > dados.json.

Observação: não são incluídos nomes de tutores nem e-mails não confirmados.
